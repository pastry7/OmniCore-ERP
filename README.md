# OmniCore ERP — Modular Enterprise Suite

OmniCore ERP is an offline-first, responsive, and geometrically balanced modular Enterprise Resource Planning application built with modern web technologies. Engineered with a minimal high-contrast slate colorway representation, strict structural borders, and modular view architectures.

---

## 🚀 Key Modules

- 📊 **Executive Dashboard**: Dynamic data summaries, operational diagnostics, and interactive performance charts.
- 👥 **CRM & Sales Pipeline**: Active consumer lookup lead tracking, deals pipelines, and outstanding balance status.
- 📦 **Inventory & Supply Chain**: Multi-type SKUs management, dynamic stock updates with safety margins, and supplier registries.
- 📄 **Invoicing & Billing**: Generate personalized commercial quotes and dispatch beautiful, print-optimized billing contracts (with complete navigation and background hiding on standard printers).
- ⚖️ **Accounting Ledger**: Track debits & credits on the corporate journals, generate dynamic Profit and Loss statements, and forecast municipal tax allocations.
- 💼 **HR & Payroll**: Onboard staff resources, manage leave request workflows, and perform single-click global wage payroll processing.
- 🧠 **Astra AI Advisor**: Real-time context-aware business insights bot designed with modern readable typographical contrasts.
- ⚙️ **Data Portability**: Switch instantly between Retail, Services, and Manufacturing industry layouts. Full-state export and restoration backing via lightweight JSON schema configurations.

---

## 🛠️ Technological Anatomy

- **Framework**: [React 18+](https://react.dev/) using modular functional components and TypeScript context states.
- **Language**: [TypeScript](https://www.typescriptlang.org/) for complete type-safety.
- **Build System**: [Vite](https://vitejs.dev/) for sub-millisecond hot module reloads.
- **Styling**: [Tailwind CSS Custom V4 Variant](https://tailwindcss.com/) mapped to a custom high-contrast geometric balanced layout.
- **Vector Icons**: [Lucide React](https://lucide.dev/guide/lucide-react).
